# Control and SCADA Systems – Hands-on Resources

This repository provides source code and hands-on video guides for the textbook **Control and SCADA Systems** by **Dr. Chau Truong**.

The textbook explains the theoretical background and design principles of industrial control and SCADA systems. This repository provides the practical project files and video playlist so that learners can open the source code, run the exercises, and verify the final results.

## Hands-on Video Playlist

The hands-on videos are available in the following YouTube playlist:

[Control and SCADA Systems – Textbook Hands-on Guides](https://youtube.com/playlist?list=PLwJhqgC1TtqYxbwkUlwHcTWVk-lGlQ9Ty)

Each video demonstrates one practical exercise from the textbook, including PLC logic, SCADA/HMI configuration, PLCSIM Advanced execution, HMI Runtime testing, and final result verification.

## Project Files

* `Control and SCADA Codes.zap20` – Main TIA Portal project archive for the textbook exercises
* `EnergyMeters.zip` – Energy meter simulation resources

## Recommended Workflow

1. Download the required project files from this repository.
2. Open or retrieve the TIA Portal project archive.
3. Follow the corresponding hands-on video in the playlist.
4. Compile and download the PLC program.
5. Run the WinCC Unified HMI Runtime.
6. Verify the final result on the SCADA/HMI screen.

## Software Used

* TIA Portal
* PLCSIM Advanced
* WinCC Unified

## Notes

The videos are intended as practical hands-on guides, not as full theoretical lectures. The theoretical explanation, design principles, and detailed background are provided in the textbook.

For the best learning experience, read the corresponding textbook section first, then follow the hands-on video using the project files in this repository.
